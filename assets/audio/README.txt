Add your ambient background track here as: ambient.mp3

The mute/unmute button won't produce sound until this file exists — that's
expected, not a bug. The site references it at assets/audio/ambient.mp3, so
matching that exact filename means no code changes are needed once you add it.

Quick way to get one:
1. Go to https://pixabay.com/music/search/celtic%20harp/ or
   https://pixabay.com/music/search/harp%20instrumental/
2. Preview a track, click Download, choose MP3.
3. Rename the downloaded file to ambient.mp3 and drop it into this folder
   (assets/audio/), replacing this README if needed.
4. Re-upload/commit the file to your GitHub repo.

Notes:
- Keep it instrumental and royalty-free/licensed for web use — do not use
  actual commercial LOTR soundtrack tracks, as those are copyrighted.
- Good search terms: "celtic harp ambient", "fantasy forest strings",
  "ethereal choir ambient", "medieval ambient instrumental".
- Keep the file reasonably small (under ~5MB) so the page loads quickly.
